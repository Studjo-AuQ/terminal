3. Welche Daten werden verarbeitet?

✓ Kurz zusammengefasst: Das Studjo Infoterminal verwendet keine Werbe-Cookies, kein Tracking, keine Analyse-Tools und kein Kontaktformular. Es gibt keine Nutzerkonten. Es werden insbesondere keine Geburtstage, Gesundheitsdaten oder vergleichbare sensible Angaben von Werkstattbeschäftigten veröffentlicht. Bei einzelnen Terminen kann ausschließlich eine freigegebene dienstliche Kontaktperson genannt werden.

Beim Aufruf der Website fallen technisch Verbindungsdaten an, insbesondere IP-Adresse, Datum und Uhrzeit des Abrufs, aufgerufene Datei sowie Browser- und Geräteinformationen. Beim derzeitigen Hosting entstehen diese Daten insbesondere beim Hosting-Anbieter GitHub Pages.

Die Website lädt keine Schriftart von Google Fonts oder einem anderen externen Schriftarten-Anbieter. Verwendet werden lokal beziehungsweise auf dem Gerät vorhandene Schriften.

Einige Funktionen speichern rein technische Einstellungen nur lokal im Browser auf dem jeweiligen Gerät. Diese Daten werden durch diese Funktionen nicht an Studjo oder an einen Analysedienst übertragen. Mehr dazu in Abschnitt 9.

6. Externe Links, ConSense und Nachrichten

ConSense und interne Johanneswerk-Inhalte

Mehrere Kacheln des Terminals verweisen direkt auf Dokumente oder Informationen im internen Qualitätsmanagement-System ConSense. Dadurch kann die jeweils dort bereitgestellte aktuelle Fassung eines Dokuments aufgerufen werden. Das Terminal hält diese Dokumente nicht als eigene Kopie vor.

Eine Verbindung zum internen Ziel entsteht erst nach einer bewussten Bestätigung. Beim ersten Klick auf einen internen ConSense-Link zeigt das Studjo Terminal zunächst einen Hinweis. Erst mit „ConSense öffnen“ wird die interne Zielseite in einem neuen Tab aufgerufen.

Allgemeine Nachrichten

Inhalte von Deutschlandfunk / Nachrichtenleicht, Tagesschau und kobinet-nachrichten werden derzeit serverseitig automatisiert abgerufen und anschließend als statische JSON-Dateien im Terminal bereitgestellt.

Externe Bilder aus den RSS-Feeds werden nicht übernommen. Dadurch lädt der Browser beim Lesen der Nachrichten keine Nachrichtenbilder direkt von diesen Anbietern oder deren Bild-/CDN-Servern nach.

Beim normalen Lesen der bereits bereitgestellten Nachrichten findet deshalb kein direkter Browserabruf bei diesen Nachrichtenanbietern statt.

7. Externe Inhalte mit vorheriger Zustimmung

Einige Funktionen werden bewusst erst nach einer aktiven Entscheidung des Nutzers geladen. Vor dem Klick wird keine externe Seite in das jeweilige iframe eingesetzt.

LearningApps.org

Die Lernübungen zu Werkstattrat, Gewaltschutz und Arbeitssicherheit werden von LearningApps.org bereitgestellt. Beim Öffnen der Studjo-Seite wird die LearningApp noch nicht geladen.

Erst nach dem Klick auf „Zustimmen und Übung laden“ erhält das eingebettete Fenster die Adresse von LearningApps.org. Erst dann wird eine Verbindung zu LearningApps.org aufgebaut. Dabei können insbesondere IP-Adresse sowie technische Informationen zu Browser und Gerät an LearningApps.org übertragen werden.

Die Zustimmung wird vom Studjo Terminal nicht gespeichert. Beim erneuten Aufruf muss erneut aktiv zugestimmt werden.

mobil.nrw und VRR

Auch die eingebetteten Fahrplan- und Abfahrtsdienste werden erst nach aktiver Zustimmung geladen. Ohne diesen Klick findet über das jeweilige iframe keine Verbindung zum Anbieter statt.

Informationen zum Datenschutz von mobil.nrw: mobil.nrw/datenschutz.html

Informationen zum Datenschutz des VRR: vrr.de/datenschutz

8. Termine und NRW-Schulferien

Termine und NRW-Schulferien werden im Studjo Terminal aus der lokalen Datei termine.json geladen. Diese Datei liegt zusammen mit den übrigen Terminal-Dateien auf demselben Server.

Für die Anzeige der Schulferien wird keine externe Schulferien-Webseite und keine externe API aufgerufen. Beim Öffnen des Kalenders entsteht deshalb keine zusätzliche Verbindung zu einem Schulferien-Anbieter.

Die landesweit festgelegten Ferienzeiten für Nordrhein-Westfalen werden manuell in der zentralen Datei gepflegt. Bewegliche Ferientage einzelner Schulen gehören nicht automatisch zu dieser landesweiten Liste.

Bei Andachten kann optional ein dienstlicher Ansprechpartner angezeigt werden. Hierfür sollen nur freigegebene dienstliche Angaben verwendet werden. Namen oder andere personenbezogene Angaben von Werkstattbeschäftigten werden in der Terminpflege nicht vorgesehen.

9. Lokaler Browserspeicher und Offline-Funktion

Das Studjo Terminal verwendet an einigen Stellen localStorage sowie den technischen Browser-Cache / Cache Storage. Dies dient ausschließlich der Bedienung und Funktionsfähigkeit.

Zum Beispiel können lokal gespeichert werden:

  • Einstellung der Schriftgröße und weiterer Bedienhilfen,
  • Aktiv-/Inaktiv-Einstellung des Gongs,
  • lokale Einstellungen zur Kacheldarstellung,
  • technische Zeitpunkte für das Offline-Vorladen,
  • Seiten und lokale Dateien für die Offline-Nutzung.
✓ Diese lokalen Einstellungen sind nicht mit einem Benutzerkonto verbunden.
✓ Das Studjo Terminal sendet diese lokalen Einstellungen nicht an Studjo, GitHub oder einen Analysedienst.
✓ Es werden damit keine Nutzungsprofile erstellt.

Die lokal gespeicherten Daten können durch das Löschen der Website-Daten bzw. des Browser-Speichers auf dem jeweiligen Gerät entfernt werden.
